# Sample Clean-deploy map (TXT).
# Lines starting with @ set the destination folder for following file names.
# Comments (#) and blank lines are ignored.
# Leading/trailing spaces and tabs after @ (and around file/URL lines) are
# trimmed; a bad line is skipped with a warning so later sections still run.
# Match File against staged FileName, leaf without NNNN_ prefix, URL path leaf,
# or full http(s) URL (HMD-027). http(s) entries are also harvested into the
# download queue (InputPath optional when the map has ≥1 URL).
# Wildcards use PowerShell -like (not regex): * = any sequence, ? = one character.
# Case-insensitive. A glob copies all matching Clean files.
#
# @C:\Deploy\App1
# https://downloads.example.com/example.zip
# program.exe
#
# @C:\Deploy\App1\Plugins
# *.pgi

# Relative destinations work too (resolved from the process working directory):
@out\deploy-demo\app1
favicon.ico

@out\deploy-demo\shared
*.ico
